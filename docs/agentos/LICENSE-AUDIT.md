# AgentOS atlas / adoption matrix — license audit

Real audit, run against the live GitHub API on 2026-11-25, not re-trusting the matrix's own
`audit_state` column (every one of its 132 rows was self-flagged
`PRIOR_BLUEPRINT_REVIEW__CURRENT_SOURCE_AUDIT_REQUIRED` — unverified). Raw per-repo results
in `license-audit-raw.json`, generated by a one-off script, not hand-typed.

**Nothing in this matrix is adopted/vendored into UAP as a result of this audit.** This only
answers "is it legally safe to adopt," not "should we." That decision stays separate, per
item, when (if ever) a specific feature is actually built from one of these.

## Result: 103 clear / 2 hard-blocked / 27 need a human license read

### Hard-blocked — copyleft, cannot vendor into a closed commercial product

| Repo | License | Why it's blocked |
|---|---|---|
| `OHF-Voice/piper1-gpl` | GPL-3.0 | Already correctly avoided per prior decision (memory: "Kokoro Apache-2.0 = GPL-piper swap"). This audit confirms that call was right — GPL-3.0 is viral; linking it into a proprietary server would obligate releasing UAP's own source. |
| `jiayaoqijia/cryptoskill` | AGPL-3.0 | Even stronger than GPL — network use alone triggers the share-alike obligation. Do not import code or run it as a linked service. |

### Needs a human license read — GitHub reports no SPDX license (legally all-rights-reserved by default)

27 repos. A missing LICENSE file does not mean "do whatever" — under copyright law it defaults
to **no permission granted**, stricter than GPL. Each of these needs an actual human to open
the repo and check for an unlisted LICENSE/COPYING file, a statement in the README, or a
dual-license notice GitHub's detector missed, before a single line is copied.

- `cryptonomicsed-byte/helixmain`, `cryptonomicsed-byte/omokoda-smithers`, `cryptonomicsed-byte/okf-security-pipeline` — our own org's repos; license is whatever we already decided, just not declared in a LICENSE file. Low risk, easy fix: add one.
- `n8n-io/n8n` (NOASSERTION — n8n is actually Sustainable Use License, a source-available-but-restricted license GitHub doesn't map to an SPDX id; this is NOT MIT and NOT freely reusable commercially)
- `daoism-systems/solidity-audit-skills`, `chaploud/clojure-skills`, `LISK819129/OpenNPC`, `JarvisUSTC/DoctorAgent-RL` (NOASSERTION — same caution: GitHub detected *something* but couldn't map it to a known SPDX id; read the actual file)
- 18 more with no license file detected at all: `remotion-dev/skills`, `fractal-nyc/software-engineering-go-launch-checklist`, `giladHaimov/Smart-Contract-AI-Audit-Skill`, `pashov/ai-web3-security`, `dilukangelosl/web3-ai-skills`, `LollyTim/solidity-evm-skill`, `Neph0s/awesome-llm-role-playing-with-persona`, `tencent-ailab/persona-hub`, `InteractiveNLP-Team/RoleLLM-public`, `actionbook/rust-skills`, `MystenLabs/sui-dev-skills`, `polyglotdev/best-practice-skills`, `iwillig/clojure-skills`, `iwillig/agentic-engineering-with-clojure`, `kodustech/awesome-agent-skills`

Three already carry a real, non-MIT license worth naming even though they weren't in the
"no license" bucket: `anthropics/evals` is **CC-BY-4.0** (attribution required, fine for
reference/evaluation material, not typically how you'd license *code* — check what's
actually being reused), `SnapdragonGameStudios/mindsand-engine` is
**BSD-3-Clause-Clear** (permissive, patent-clear variant — fine), `awslabs/hcls-agent-skills`
is **MIT-0** (public-domain-equivalent, fine), `Newmcpe/rust-coding-skill` is **WTFPL**
(permissive but unusual — a corporate legal reviewer may still want a real license on file

## What this audit does NOT cover

- Trademark/brand asset review (mascots, logos, product names) — the matrix's own
  `caution_or_gate` column flags several of these (OpenMausBot's Grok-styled branding); not
  re-checked here, still an open item.
- Whether a "clear" license's *code quality or security* is acceptable — a separate review.
- The AgentOS atlas/matrix's own accuracy beyond the license field — `what_we_take` and
  `adoption_type` columns are the matrix author's claims, not verified by this pass.
